# TradingTrainer

Веб-терминал для тренировки скальпинга на криптовалютных фьючерсах: live-стакан и график, симулятор исполнения, реплей истории Binance, журнал сделок и две CatBoost meta-модели для оценки входов/усреднений и выходов.

> [!IMPORTANT]
> Live-режим получает реальные публичные рыночные данные, но сделки исполняются только локальным `PaperBroker`. Проект не подключается к торговому аккаунту, не требует API-ключей и не отправляет реальные ордера на биржу.

## Возможности

- Live-данные Binance, Bybit, OKX и KuCoin через `ccxt.pro`.
- USDT-M perpetual-инструменты и таймфреймы `1m`, `3m`, `5m`, `15m`, `30m`, `1h`, `4h`.
- Настраиваемая загрузка до 3000 исторических свечей перед запуском live-потока.
- Стакан с агрегацией цены и управлением ордерами мышью.
- Лента принтов с фильтром минимального USDT-объёма и объединением последовательных BUY/SELL.
- Рыночные и лимитные paper-ордера, частичное закрытие, усреднения, разворот, SL/TP и комиссии.
- Реплей Binance Futures по минутным свечам или `aggTrades`, включая OI, funding и прогрев индикаторов.
- Объём, Delta и Open Interest на графике.
- Горизонтальные уровни, трендовые линии и прямоугольники с предпросмотром; отдельный объект удаляется правой кнопкой мыши.
- Изменяемые размеры панелей и режим фокуса на графике.
- Журнал сделок с отдельным графиком, контекстом до входа/после выхода, тегами и комментариями.
- Две независимые CatBoost meta-модели:
  - `Entry / Average` оценивает каждый первичный вход и каждое усреднение;
  - `Exit` отдельно оценивает состояние позиции в момент выхода.
- Автоматическое удаление константных и сильно коррелирующих фич перед обучением.

## Быстрый запуск

Требуется Python 3.10 или новее и доступ в интернет. Браузеру также нужен доступ к CDN `unpkg.com`, откуда загружается Lightweight Charts.

```bash
git clone https://github.com/drimeF0/boostscalp.git
cd boostscalp

python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

python run.py
```

После запуска откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

Для доступа с другого устройства в локальной сети:

```bash
python run.py --host 0.0.0.0 --port 8000
```

На Windows активация виртуального окружения выполняется командой:

```powershell
.venv\Scripts\Activate.ps1
```

## Live-режим

1. Выберите биржу.
2. Укажите символ, например `BTC/USDT` или `TUT/USDT`. Запись `BTCUSDT` также нормализуется автоматически.
3. Выберите таймфрейм.
4. Включите загрузку истории и задайте число свечей. Для полного набора ML-фич нужно не менее 80 загруженных баров.
5. Нажмите **Подключить**.

Поддерживаемые адаптеры:

| Интерфейс | Рынок в CCXT |
| --- | --- |
| Binance | `binanceusdm` |
| Bybit | perpetual swap |
| OKX | perpetual swap |
| KuCoin | `kucoinfutures` |

Delta-история до подключения доступна прежде всего на Binance, поскольку для её восстановления используются raw kline-поля taker-buy volume. Доступность истории OI зависит от реализации публичного API выбранной биржи.

## Бэктест и реплей

Во вкладке **Бэктест** задайте инструмент, диапазон дат, источник цен и скорость:

- **Свечи 1m** — быстрый реплей; внутри свечи генерируется последовательность синтетических тиков.
- **Тики (aggTrades)** — более детальный реплей реальных агрегированных сделок, но требует больше времени и дискового пространства.

Недостающие публичные архивы автоматически скачиваются с `data.binance.vision` и кешируются в `data/`. Дополнительно загружаются Binance Futures metrics для OI и funding rate, если соответствующие архивы доступны.

Пробел ставит и снимает реплей с паузы. Скорость можно менять во время работы.

## Управление

Горячие клавиши можно переназначить во вкладке **Настройки**. Значения сохраняются в `localStorage` браузера.

| Клавиша | Действие по умолчанию |
| --- | --- |
| `1`–`9` | Выбор одного из девяти объёмов в USD |
| `B` | Market Buy |
| `S` | Market Sell |
| `X` | Закрыть открытую позицию |
| `C` | Отменить все лимитные ордера |
| удерживать `T` | Режим SL/TP: ПКМ устанавливает, ЛКМ отменяет |
| `Space` | Пауза/продолжение бэктеста |

Управление из стакана:

| Действие | Результат |
| --- | --- |
| ЛКМ по bid | Limit Buy |
| ЛКМ по ask | Market Buy |
| ПКМ по ask | Limit Sell |
| ПКМ по bid | Market Sell |

## Журнал сделок

Закрытые сделки сохраняются в SQLite. Нажатие на строку журнала открывает карточку со следующими данными:

- свечной график с маркерами входа и выхода;
- настраиваемый префикс до входа и суффикс после выхода;
- причины входа и выхода в виде тегов;
- свободный комментарий;
- список первичного входа и усреднений;
- агрегированные entry-фичи и отдельный снимок exit-фич.

Настройки временного контекста находятся во вкладке **Настройки**.

## CatBoost meta-модели

Модели обучаются только на накопленной локальной истории пользователя. Для каждой модели требуется минимум 20 пригодных событий и примеры обоих классов.

Доступные группы признаков:

- доходности на нескольких окнах;
- RSI, ATR и реализованная волатильность;
- объём, volume z-score и динамика объёма;
- структура свечи, EMA-тренд и положение в диапазоне;
- Delta, CVD и taker buy/sell ratio;
- spread и дисбаланс стакана на нескольких глубинах;
- VWAP, funding и изменение OI;
- размер и PnL позиции, расстояние от средней цены, время удержания и число усреднений;
- циклические признаки времени суток и дня недели.

Для расчёта полного снимка требуется минимум 61 закрытая свеча. Перед обучением признаки очищаются на train-части выборки: константы удаляются, а из пар с абсолютной корреляцией `>= 0.92` сохраняется более приоритетный признак. Список выбранных фич сохраняется рядом с моделью и повторно используется при инференсе.

Режимы работы:

- **Фильтр** может отклонять entry/average-действия ниже заданного порога.
- **Советник** только показывает оценку и не блокирует действие.
- Exit-модель всегда работает рекомендательно: закрытие позиции никогда не блокируется.

Артефакты сохраняются отдельно:

```text
models/
├── entry_meta_model.cbm
├── entry_meta_model.json
├── exit_meta_model.cbm
└── exit_meta_model.json
```

## Данные и настройки

```text
data/trades.db     SQLite-журнал сделок
data/klines/       кеш свечей Binance
data/aggTrades/    кеш агрегированных сделок
data/metrics/      кеш OI/derivatives metrics
data/fundingRate/  кеш funding rate
models/            обученные CatBoost-модели и метаданные
```

Каталоги `data/` и `models/` исключены из Git. Удаление `data/trades.db` сбрасывает журнал, а удаление `models/` — обученные модели. Настройки layout, hotkeys, объёмов и live-истории хранятся в `localStorage` конкретного браузера.

## Ограничения

- Это исследовательский paper-trading инструмент, а не production execution terminal.
- Симуляция не моделирует сетевую задержку, проскальзывание и полное прохождение заявки по глубине реального стакана.
- Качество meta-моделей зависит от количества, разнообразия и разметки пользовательских сделок.
- Оценки модели не являются финансовой рекомендацией.
